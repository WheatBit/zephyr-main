## How to Download on iPhone

### Method 1: Direct Download (Recommended)

1. **Tap any link above** in Safari or your browser
2. The raw markdown file will open
3. **Tap the share button** (square with arrow)
4. Select **"Save to Files"**
5. Choose a location (iCloud Drive, On My iPhone, etc.)
6. The file will be saved as `.md` (markdown)

### Method 2: Copy to Notes

1. **Tap any link above**
2. **Long-press** on the page
3. Select **"Select All"**
4. Select **"Copy"**
5. Open **Notes app**
6. Create new note and **paste**

### Method 3: Use GitHub App

1. Install **GitHub** app from App Store
2. Navigate to: `WheatBit/zephyr-main`
3. Switch to branch: `cursor/ambiq-hardware-docs-a3aa`
4. Browse files and tap to view
5. Use app's save/share options
